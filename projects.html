1. Crypto Address Type Classification: A Comparative Machine Learning Study

A comparative study of eight classical machine-learning classifiers for identifying cryptocurrency address types from engineered text features, using a 25,000-record synthetic research dataset.

Problem Addressed

The project investigates whether cryptocurrency wallet addresses can be identified from free-text data for applications such as fraud/scam detection and compliance.

Technologies

PythonJupyter NotebookPandasNumPyScikit-learnMatplotlibSeaborn

Implementation

  • Engineered text and cryptocurrency address pattern features.
  • Compared SVM, Logistic Regression, Decision Tree, K-NN, Naive Bayes, MLP, AdaBoost and Random Forest.
  • Used stratified train/validation splitting and evaluated accuracy, precision, recall and F1.
  • Included experiments involving a custom Random Forest with Cuckoo Hashing and an ensemble K-NN extension.

2. Employee Salary Level Classification: A Comparative Machine Learning Study

A comparative machine-learning study predicting employee salary levels from HR attributes and evaluating six classification algorithms using 10-fold stratified cross-validation on a 14,999-record dataset.

Problem Addressed

The project explores whether workforce attributes such as satisfaction, evaluation score, project count, monthly hours, tenure and department can be used to predict salary level and investigate compensation patterns.

Technologies

PythonJupyter NotebookPandasNumPyScikit-learnMatplotlibSeaborn

Implementation

  • Performed exploratory analysis of salary-level classes and HR attributes.
  • Built preprocessing pipelines using StandardScaler, OneHotEncoder and ColumnTransformer.
  • Compared Logistic Regression, Naive Bayes, K-NN, SVM, Decision Tree and MLP classifiers.
  • Used 10-fold stratified cross-validation with accuracy, weighted precision/recall/F1 and macro F1.
  • Investigated implementation and cross-validation issues during model development.

Key Result

The Decision Tree achieved approximately 61% accuracy in the reported run. The study also identified class imbalance and duplicate records as important considerations when interpreting the results.

3. Flexural Strength Prediction of Fiber-Reinforced Concrete Using Regression Models

A scikit-learn regression project that predicts the flexural strength of fiber-reinforced concrete from mix-design parameters, comparing up to 19 regression algorithms on a 278-sample dataset.

Problem Addressed

Measuring flexural strength requires casting and testing concrete specimens, which can be slow and costly. Predictive modeling can help estimate strength from mix composition and reduce trial batches.

Technologies

PythonJupyter NotebookPandasNumPyScikit-learnMatplotlibSeabornXGBoostCatBoostLightGBM

Implementation

  • Prepared 12 input features and one target variable and performed an 80/20 train/test split.
  • Compared linear, regularized, robust, tree-based, ensemble, boosting, SVR, K-NN, MLP, Gaussian Process and polynomial regressors.
  • Used StandardScaler pipelines for scale-sensitive models.
  • Tuned 14 models with 5-fold GridSearchCV using negative MSE.
  • Evaluated models using test-set MSE and R² and visualized true-versus-predicted values.

Key Result

In the reported test run, Extra Trees and Gradient Boosting each achieved approximately R² = 0.92 with MSE around 0.58. Gaussian Process and Random Forest followed at approximately R² = 0.89 and 0.88, respectively. The reported run excluded XGBoost, CatBoost and LightGBM.
